A one-line pickup line spoken by a vending machine to a passing human: it admits it is only a machine, then offers to drop something sweet for the right button-press — and swaps the exact change it would normally want for a phone number.

## The line

> I'm only a vending machine, but press my buttons right and I'll drop something sweet — exact change not required, just your number.

The setup sounds like a machine stating its limits; the punchline in the last few words turns the transaction around — instead of coins, the machine wants a number. The line is spoken by the machine itself, uses its own world (buttons, the drop, exact change), and stays cheeky and warm rather than creepy.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (131 characters, UTF-8, deterministic — two runs produce byte-identical output). The line is well within the 200-character limit, a single line with no trailing newline.
